# omo Music — Android

Native Android application, built from open-source OuterTune playback/search and library internals with its own omo UI direction, not ReVanced patches.

## Build

JDK 21, Android SDK 37, and Android Gradle Plugin dependencies required.

\`\`\`bash
cd client
./gradlew :app:assembleCoreDebug
\`\`\`

APK: \`app/build/outputs/apk/core/debug/\`.
